## Description

This year, we offer a shared task in automatic interlinear glossing for field linguistic annotations.

The task is to predict interlinear glosses, which are morpheme-level linguistic annotations (e.g., Flaschen (bottles) in German can be labelled as bottle-PL), notably used in field linguistics. Ultimately, glossing systems aim to help field linguists with the annotation task for languages under documentation, as it is mainly performed manually with little automation.
